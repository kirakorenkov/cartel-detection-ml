# Выявление картельных сговоров в госзакупках

ML-проект по обнаружению картельных сговоров в запросах котировок
(госзакупки по 44-ФЗ / 223-ФЗ) на основе косвенных признаков.

## Задача

Антимонопольный орган проверяет закупки на сговор вручную, что дорого и медленно.
Цель проекта — построить модель, которая по косвенным признакам сужает круг закупок
для проверки, повышая долю реальных картелей в выборке.

## Данные

- 15 138 закупок (Контур.Закупки + дела ФАС)
- Сильный дисбаланс классов: картели составляют 1.7% выборки (254 из 15 138)
- Сконструированы признаки трёх типов: ценовые, структурные и графовые
  (связи между участниками торгов)

> Сырые данные и выгрузки в репозиторий не включены. Выводы ячеек ноутбука,
> содержавшие построчные данные закупок, очищены.

## Методы

- Модели: Logistic Regression, Random Forest, XGBoost
- Работа с дисбалансом: SMOTE, взвешивание классов (`scale_pos_weight`)
- Валидация: кросс-валидация, доверительные интервалы метрик (bootstrap),
  оценка по метрикам для редкого класса (Recall, lift), а не по accuracy

## Результат

Лучшая модель (XGBoost на расширенном наборе признаков) повысила концентрацию
картелей в проверочной выборке в **10.6 раза** — то есть для нахождения того же
числа нарушений проверяющему нужно просмотреть кратно меньше дел.
